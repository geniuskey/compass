# EMVA 1288 Characterization

::: tip Prerequisites
[Quantum Efficiency](./quantum-efficiency.md) -> [Noise, SNR, and Dynamic Range](./noise-and-snr.md) -> this page.
:::

The **EMVA 1288** standard (European Machine Vision Association, currently Release 4.0) defines a unified methodology for measuring and reporting image sensor performance. This page summarizes its parameter set and how each item maps to the noise and signal model used elsewhere in this chapter.

EMVA 1288 is structured around a small set of physical inputs and a parameter list that downstream measurements report. The simplification it makes is a linear model: signal is proportional to incident photon number, and noise sources are independent and add in quadrature.

## Parameter set

### Sensitivity metrics

| Parameter | Symbol | Meaning |
|---|---|---|
| Quantum efficiency | $\eta(\lambda)$ | Probability that an incident photon at $\lambda$ produces a collected electron |
| Responsivity | $R$ | Slope of the photon-transfer line in DN per photon |
| Absolute sensitivity threshold | $\mu_p^\text{min}$ | Photon count at which SNR = 1 |

The sensitivity threshold is the minimum detectable photon number per pixel and is approximately

$$\mu_p^\text{min} \approx \frac{1}{\eta}\!\left(\sigma_\text{read} + \sqrt{\sigma_\text{read}^2 + \tfrac{1}{4}}\right)$$

with $\sigma_\text{read}$ in electrons.

### Noise metrics

| Parameter | Symbol | Meaning |
|---|---|---|
| Temporal dark noise | $\sigma_d$ | Read-noise floor in $e^-$ RMS at zero exposure |
| PRNU | $u_\text{PRNU}$ | Pixel-to-pixel gain non-uniformity (fraction of signal) |
| Saturation SNR | $\text{SNR}_\text{max}$ | Best achievable SNR before saturation |

In the shot-noise-limited regime, $\text{SNR}_\text{max} \approx \sqrt{\mu_\text{sat}}$ where $\mu_\text{sat}$ is the saturation signal in electrons.

### Capacity metrics

| Parameter | Symbol | Meaning |
|---|---|---|
| Saturation capacity | $\mu_\text{sat}$ | Maximum signal in $e^-$ (full well) |
| Dynamic range | DR | Ratio of $\mu_\text{sat}$ to noise floor |
| Useful bits | $b_\text{useful}$ | Effective ADC resolution given noise |

The useful bits are computed from $\text{DR}$ as $b_\text{useful} = \log_2(\text{DR}_\text{linear})$ and may be lower than the ADC's nominal bit depth when read noise exceeds 1 DN.

### Dark current metrics

| Parameter | Symbol | Meaning |
|---|---|---|
| Mean dark signal rate | $\mu_I$ | Dark current in $e^-/\text{s}$ at nominal $T$ |
| Dark current doubling temperature | $T_d$ | $\Delta T$ that doubles $\mu_I$, typically 6–8 °C |
| DSNU | $\sigma_y^\text{dark}$ | Spatial standard deviation of dark signal |

The dark signal model is $\mu_\text{dark}(T, t) = \mu_I(T)\,t$. Combined with the Arrhenius dependence from [Noise, SNR, and Dynamic Range](./noise-and-snr.md), this lets the standard report dark current at any operating temperature from a single calibration.

## SNR curve and grade reporting

EMVA 1288 expects the SNR-versus-irradiance curve to be reported with:

- The actual measured curve (limited by read noise at low end, shot noise in the middle, PRNU at the top)
- The **ideal shot-noise-limited** reference $\text{SNR}_\text{ideal} = \sqrt{N}$

The gap between the two curves quantifies how far the sensor deviates from ideal photon counting and is the most informative summary plot in the standard.

A typical EMVA 1288 report tags each parameter with a quality grade — for example:

- **Excellent** — best-in-class performance for that metric
- **Typical** — common production range
- **Below typical** — may limit specific applications

The grading is not part of the linear model itself; it is a convention for quickly flagging which parameter is the bottleneck for a given imaging task.
